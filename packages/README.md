# packages/ — 可复用模块

本目录存放从分析脚本中抽取的、可被独立引用与测试的模块。

| 包 | 语言 | 说明 |
|---|---|---|
| [`protocol/`](protocol/README.md) | Python | `jcy_protocol`：监控/信令双通道 AES-128-CBC 加解密原语 + 已验证测试向量 |

## 约定

新增包需要满足：

1. 有独立的 `README.md`，说明定位、安装、用法与边界
2. 有可运行的测试，且被 `pnpm test` 覆盖
3. 不与 `out/client/` 的取证产物重复实现——抽取而非复制

## 分层理由

`out/` 下的脚本是**分析过程记录**（含大量迭代版本，如 `gg_dart_hook` 1–8），
不适合被新代码直接依赖；需要稳定接口的能力抽取到本目录，
形成「过程产物 / 可复用库」的清晰分层。
